# Dağınık Oda

Yapay zekâ, bilim ve merak üzerine kişisel defter ve portfolyo sitesi.

🔗 **Canlı site:** https://nur-hidir.github.io/dagiknoda/

## İçerik

- **Anasayfa:** Kısa tanıtım
- **Hakkımda:** Terminal teması, hobi rafı ve şu an neler yaptığım
- **Portfolyo:** CV, projeler, deneyim ve yetenekler
- **Blog:** Açık kitap görünümünde okunan yazılar
- **İletişim:** Bana ulaşma yolları

## Teknolojiler

HTML, CSS, JavaScript, Tailwind CSS (CDN), Phosphor Icons, Google Fonts

## Çalıştırma

Sunucu ya da kurulum gerektirmez. `index.html` dosyasını tarayıcıda açmak yeterlidir.
